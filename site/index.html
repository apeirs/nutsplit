nutsplit: ecash a podcast receives, paid out to everyone in its split

Listeners send Cashu to the show (NUT-18 or NIP-61 nutzaps). nutsplit books every sat to the episode's podcast:value recipients, the way Hopp and Sovereigncast split Lightning, and pays each host, guest and editor in one Lightning payment per batch. A public ledger shows each of them what they were owed and paid.

Listeners' wallets

  • boosts with a message
  • streaming sats
  • NUT-18 POST or NIP-61 nutzap
→Cashu ecash

nutsplit (the show's instance)

  • swaps each payment into its own wallet
  • books every sat by the feed's podcast:value, incl. time splits
  • public ledger, books checked against the wallet
→one melt per recipient per batch

Everyone in the split

  • Lightning addresses paid by the mint
  • keysend shares kept owed, never redistributed

Today a show's ecash goes to the show as a whole: Hopp's ADR 0014 says so, and Sovereigncast sweeps it to one wallet. nutsplit is the missing split for that money.

Run it

git clone https://github.com/apeirs/nutsplit && cd nutsplit
npm ci
npm test              # 87 tests, no network
node demo/run.ts      # the run above, against the public test mints
node demo/nutzap.ts   # the nutzap run (local relay, testnut)

Node 24 or newer. For a show: nutsplit serve --feed <rss> --mint <mint> --public-url <url>, then put the podcast:txt purpose="cashu" line it prints in the feed. Details, rules and limits in the README.
